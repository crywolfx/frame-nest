## 数据

- `data/pois.json`：地点、为什么值得去、执行动作与来源引用。
- `data/itinerary.json`：五日顺序、交通段、价格和地图默认安排。
- `data/events.json`：Ron Mueck、盂兰盆高峰与深川八幡祭语境。
- `data/sources.json`：官方、地图与经验来源登记。
- `data/design-tokens.json`：东京导视纸张主题。
- `maps/itinerary-map.html`：可直接打开的互动地图。

地图虚线只表示当天访问顺序，不是正式道路几何或逐步导航。实时路线以运营方、站内电子屏和出发当天导航为准。
